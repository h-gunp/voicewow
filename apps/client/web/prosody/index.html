실제 음성으로 만든 그래프
준비된 문구는 맥의 한국어 음성, 내 대본은 Supertonic 3의 한국어 합성 음성을 분석해요. 글자 수에 맞춰 임의의 곡선을 그리지 않아요. 생성된 음성도 읽기 실수가 있을 수 있어요.

가이드 따라 하기
각 녹음의 중간 높이·크기를 맞추고, 확인된 목소리끼리 속도를 대략 맞춰 비교해요. 연습 안내는 선택한 구간의 시작과 끝에서 측정한 변화에 기반해요. 예시와 다르다고 말하기가 틀린 것은 아니에요.

문장과 시간 구간
긴 대본은 문장별로, 긴 문장은 짧은 조각으로 나눠 연습해요. 앞·중간·끝은 가이드의 측정 가능한 시간을 기준으로 정해요. 해당 글자를 인식한 결과는 아니에요. 짧은 말은 전체를 듣고, 긴 구간은 앞뒤 소리를 조금 함께 들려드려요.

녹음과 측정
높낮이는 65–500Hz 범위에서 추정해요. 자음이나 불분명한 소리는 빠질 수 있고, 다른 사람의 목소리는 구별하지 못해요. 시작·끝의 비교가 어려우면 연습 방향을 자동으로 정하지 않아요.
