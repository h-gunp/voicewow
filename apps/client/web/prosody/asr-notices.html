음성 인식 모델·라이선스 고지

VoiceMate의 음성 대본 위치 표시는 sherpa-onnx와 한국어 Streaming Zipformer 모델을 사용합니다. 인식은 기기 안에서 처리하며 음성·대본을 서버로 전송하지 않습니다.

한국어 모델

원본 모델 카드는 Apache-2.0을 선언합니다. 변환 모델 카드는 원본 출처를 연결하지만, 변환본의 별도 라이선스 선언은 명시되지 않았습니다. 변환 모델 재배포 권리는 확인 중입니다. 아래 출처·전문을 확인해 주세요. 이 안내는 별도의 이용 허가를 부여하지 않습니다.

공식 변환 절차 기록(icefall PR #1655)에는 원본 pretrained.pt를 epoch-99.pt로 연결해 ONNX로 내보내고 해당 변환 저장소에 올리는 과정이 있습니다. 미확인 사항은 실행 당시 원본 revision의 고정 여부, 현재 배포 파일의 독립 재현, 변환 저장소 자체의 별도 라이선스 표기입니다. 변환 기록이 없다는 뜻은 아닙니다.

  • 보관된 변환 모델 카드 · 사용 중인 변환 모델 버전
  • Apache License 2.0 전문

모델 가중치는 사이트 파일에 포함하지 않고 사용자가 준비할 때 고정된 공개 주소에서 내려받습니다. 직접 다운로드 방식이 추가 권리를 보장하거나 라이선스 의무를 없애지는 않습니다. 학습 데이터·평가 음성의 재배포 권리는 별개입니다.
