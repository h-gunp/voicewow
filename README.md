# VoiceMate 발음 모델 정적 파일

`chegrowk/ko-phone-int8`의 동일 양자화 가중치를 ORT 형식으로 저장한 배포 파일이다. 사용자 음성이나 분석 결과는 포함하지 않는다.

원본 출처와 revision, 변환 설정, 전체 크기와 SHA-256은 `source.json`에 기록한다. 원본 Apache-2.0 라이선스는 `LICENSE`에 보존한다. 추가 학습과 재양자화는 하지 않았다.

`ko-phone-int8.ort.part00`부터 `.part21`까지 순서대로 이어 붙이면 356,216,776바이트다. 결합 SHA-256은 `a280f2679f08c809ae3c5ad55abe15dc78803e06143cc9b485c143612652765e`다.

이 별도 자산 브랜치는 웹 배포의 용량 제한 때문에 사용한다. 앱은 고정 커밋의 공개 파일을 읽고 크기와 전체 해시를 검증한 뒤 기기 내부에서만 음성을 분석한다.
