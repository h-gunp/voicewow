# 훈련 진입 워밍업과 제품 문구 정리

**요청:** 사용자 피드백에 따라 면책성 제품 문구를 제거하고, 별도 도움말의 준비 과정을 발음·높낮이 훈련 진입으로 옮긴다.

**구현:** 기존 Flutter 앱의 탭 전환·음성 정리 흐름을 유지한다. 발음·높낮이 탭 진입 시 같은 영역에 3단계 워밍업을 표시하고 완료 또는 건너뛰기 뒤에만 해당 훈련을 생성한다. 도움말 왕복·재녹음에는 다시 표시하지 않는다. 자세 풀기, 배에 손을 얹고 코로 편하게 들이마시기, 입으로 부드럽게 내쉬기를 직접 넘긴다. 기본 시각 디자인과 글자 확대를 유지한다.

**범위:** `app.dart`, `widgets/training_guide.dart`, 새 `widgets/training_warmup.dart`, 관련 Flutter UI 문구·테스트, `web/prosody` 문구·해당 테스트, 루트 `AGENTS.md`다. 음성 인식·음량 처리 알고리즘과 기기 내 처리 정책은 바꾸지 않는다.

- [x] Flutter·높낮이 웹 화면의 면책성 문구를 제거한다. 실제 오류, 조작 안내, 불확실 결과 의미는 보존한다.
- [x] 별도 준비 루틴을 도움말에서 제거하고 훈련 진입에 연결한다. 준비 중 뒤로 가기·탭 이동, 완료·건너뛰기, 도움말 왕복, 큰 글씨를 검사한다.
- [x] 전체 회귀 검사·분석·릴리스 빌드 및 독립 검토를 완료한다. Flutter 339개·Node 477개 통과, 분석 오류 없음, JS 릴리스 빌드 성공이다. 별도 Wasm 대상은 빌드하지 않았다.
- 소스 커밋·푸시 후 동일 공개 Sites 프로젝트에 배포한다. 배포 영수증은 `.local/warmup-deployment.json`에 기록한다.

호흡 동작 근거: 사용자 제공 사진과 [NHS의 편안한 호흡 안내](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/)다. 목을 누르거나 호흡을 강제로 늘리는 동작은 추가하지 않는다.
