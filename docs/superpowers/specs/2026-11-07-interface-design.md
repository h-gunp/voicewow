# VoiceMate 화면 정리안

상태: 2026-11-07 사용자가 “맏긴다”라고 답해 제안 방향과 세부 디자인 판단을 맡겼다.

후속 통합: 사용자가 퀴즈·높낮이와 디자인을 함께 유지하도록 요청했다. 아래 등록 화면 관련 기록은 이전 브랜치 구현 이력이다. 현재 적용은 최신 `main`의 음량·발음 퀴즈·내 문장·복습·높낮이 기능에 같은 시각 체계를 이식하며, 최신 버전에서 제거된 화자 등록은 재도입하지 않는다. 진행·검증 기록은 `../plans/2026-11-07-full-feature-design-integration.md`에 둔다.

## 목적과 확인한 코드

사용자는 앱 전체에서 AI가 생성한 템플릿처럼 보이는 디자인을 개선하도록 요청했다.
현재 구현은 460px 고정 폭의 둥근 외곽 프레임, 두 개의 동일한 선택 카드, 중앙 정렬 설명문, 캡슐 형태의 그라데이션 게이지를 사용한다.
이 요소를 정리하면 사용자가 지적한 인상을 줄일 수 있다는 디자인 판단이다. 사용자 반응을 검증한 사실은 아니다.

## 검토한 접근

1. 색·모서리만 정리하는 안이다. 변경은 적지만 등록 화면과 측정 화면의 정보 밀도는 유지된다.
2. 공통 테마·레이아웃·정보 위계를 함께 정리하는 안이다. 아래 제안에 해당하며 기존 화면과 동작을 재사용한다.
3. 탐색 구조와 측정 표현을 새로 만드는 안이다. 기능 변화와 회귀 범위가 커 현재 요청에는 필요하지 않다는 판단이다.

사용자가 맡긴 방향은 2번이다. 구체적인 색과 간격은 구현자가 결정한다.

## 제안한 화면

- 공통 화면은 밝은 중립 바탕과 먹색 글자를 사용한다. 외곽의 휴대폰 모양 프레임과 불필요한 그림자를 없애고 포인트색은 한 가지로 제한한다. 빨간 기준선은 유지한다.
- 등록 화면은 제목, 준비·수집·완료 상태, 실제 수집 개수, 주요 버튼 순서로 정리한다. 모델 크기·기기 내 처리·새로고침 시 삭제·실험 기능 안내를 읽을 수 있게 나눈다.
- 상황 선택은 두 개의 넓은 선택 행과 구분선을 사용한다. 현재 노출하는 일대일 대화와 발표, 선택 접근성, 시작 조건을 유지한다.
- 측정 화면은 입력 수준과 세로 게이지, 시작·중지 조작을 먼저 표시한다. 화자 등록·삭제와 환경 분석 설명은 그다음 구역으로 나눈다. 오류 안내와 상대 척도 고지는 유지한다.
- 게이지는 단색 막대와 작은 모서리를 사용한다. 0–120 수직 좌표, 빨간 상·하한, 실제 값에 따른 채움, 동작 줄이기 설정을 유지한다.
- 진단 화면은 왼쪽 정렬과 구분선을 사용한다. 마이크 없이 진단·모델 고지에 접근하는 경로를 유지한다.
- 좁은 화면은 한 열로 스크롤하며 넓은 화면은 프레임 없이 읽기 폭을 제한한다. 글자 200% 확대에서 버튼과 기준선 라벨이 겹치지 않아야 한다.

## 변경 범위와 경계

변경 대상은 `app_theme.dart`, `app.dart`, `screens/enrollment_screen.dart`, `screens/scenario_screen.dart`, `screens/meter_screen.dart`, `widgets/volume_gauge.dart`와 필요한 화면 테스트다.
SessionController, 오디오 포트, 워커, 보정값, 참고 범위, RNNoise와 화자 판별 동작은 변경하지 않는다.
새 의존성, 새 로고·이미지, 가짜 파형·측정값·정확도 수치는 추가하지 않는다.
공개 저장소 push나 배포는 이 작업에 포함하지 않는다.

## 검증

수정 전 Flutter 테스트 66개가 통과했다.
구현 후 Flutter 테스트, 정적 분석, release 웹 빌드와 좁은 화면·넓은 화면·글자 확대 확인을 수행한다.
브라우저 자동화는 현재 URL을 신뢰성 있게 확인하지 못해 중단됐다. 별도 렌더링 확인으로 대체하더라도 실제 브라우저 및 마이크 검증과 구분해 보고한다.
실제 기기 음향 정확도는 디자인 검증으로 주장하지 않는다.

## 구현 및 검증 결과

공통 헤더와 720px 읽기 폭, 목록형 상황 선택, 실제 수집 개수 진행 표시, 단색 게이지와 숫자 눈금, 넓은 화면의 측정·조작 두 열 배치를 반영했다.
진단은 입력 상태·화자 모델·처리 정보 구획으로 나눴다. 버튼과 진단 제목도 공통 TextTheme의 글꼴을 상속한다.
Flutter 테스트 70개, 정적 분석, 최종 release 웹 빌드가 통과했다.
390×844와 1280×900의 Flutter 렌더링 10장을 확인했다. 측정 화면은 FakeAudioPort 합성 입력이며 브라우저 캡처가 아니다.
독립 코드 리뷰에서 Critical/Important 결함은 확인되지 않았다. 실제 브라우저·화면낭독기·마이크 동작과 기기 음향 정확도는 미검증이다.
변경은 로컬에 두며 커밋·push·공개 배포는 수행하지 않았다.
