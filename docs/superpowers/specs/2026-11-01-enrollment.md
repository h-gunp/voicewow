# 초기 목소리 등록 설계

첫 화면에서 등록을 안내하고 나중에 등록을 허용한다. 마이크와 음성 모델 준비, 3개 구간 수집, 실패와 재시도, 완료를 구분한 뒤 상황 선택으로 이동한다. 측정 화면에서는 재등록에 진입할 수 있다. 등록 데이터는 페이지 메모리에만 유지한다.

중복 등록은 차단하고 소음 억제와 발화 감지가 준비되지 않으면 시작하지 않는다. 측정 화면은 상대 입력 막대, 목표 범위, 핵심 상태와 조작을 남기고 자세한 진단과 모델 고지는 별도 정보 화면으로 옮긴다. 실험 화자 판정과 상대 입력의 한계는 보존한다. 마이크 실사용과 외부 음성 전송은 검증에 사용하지 않는다.
