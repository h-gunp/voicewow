# 수동 환경음 수집 설계

사용자는 환경음 수집 버튼으로 기준선을 정한 뒤 기존 RNNoise와 VAD로 발화를 표시하는 방식의 구현·최종 검토·푸시·기존 Sites 배포를 승인했다.

## 동작

- 현재 마이크 연결에서 `주변 환경음 듣기`를 누르면 사용자는 말하지 않고 5초 동안 주변 소리를 수집한다. 별도 마이크 연결이나 음성 저장·전송은 추가하지 않는다.
- 앱 RNNoise 이전의 브라우저 입력 에너지를 사용하며 주변 대화도 포함한다. 발화·비발화 판정을 수집 필터로 쓰지 않는다. 발화 막대는 수집 중 비운다.
- 수집 성공 후 상황별 기본 범위에 보정값을 적용하고 같은 캡처 세션 동안 고정한다. 말하거나 잠시 말을 멈춰도 기준선은 움직이지 않는다.
- 재측정 중에는 이전 성공 기준을 유지하며 실패·사용자 취소도 같은 입력 조건이면 이전 기준을 보존한다. 입력 끊김·오래된 프레임·기기/설정 변경·중지/화면 이탈은 기준을 폐기한다. 수집 완료 자체는 마이크를 재시작하지 않는다.
- 기본 상황 범위로 측정하는 기능도 유지한다. 수집은 선택 기능이며 초기부터 자동으로 실행하지 않는다.

## 제한된 실험 규칙

아래 수치는 구현을 위한 실험적 초기값이며 음압 교정이나 적정 발성량 검증 결과가 아니다.

- 서로 겹치지 않는 10ms 입력 프레임 500개를 관찰한다. 양의 유한 에너지이면서 클리핑이 없는 표본이 400개 이상이어야 한다. 클리핑 비율이 10% 이상이면 실패한다.
- 버튼 요청의 AudioContext 시각 이전에 시작한 프레임은 수집하지 않는다. VAD 또는 RNNoise가 준비되지 않아 유효한 raw 분석 프레임을 제공하지 못하면 수집을 시작하지 않는다.
- 유효 에너지의 중앙값을 `10*log10`으로 변환한다. 양의 값이 없는 디지털 무음은 실패하며 큰 단발 소리를 기준으로 삼지 않는다.
- 유효 에너지의 사분위 범위가 12dB를 초과하면 불안정한 수집으로 처리한다. 주변 대화 자체를 금지하는 조건은 아니다.
- 보정값은 `clamp((noiseDbfs + 60) / 10, 0, 3)`을 소수 첫째 자리로 반올림한다. -60dBFS 이하 0, -50에서 1, -40에서 2, -30 이상에서 3 참고 단위다. 기존 최대 이동량 3을 유지하며 이를 SPL/dBA로 부르지 않는다.
- 수집과 표시의 처리 경로가 다르므로 주변 에너지에 여유값을 더해 절대 발화 목표라고 주장하지 않는다. 실제 환경·기기별 기준선 타당성은 별도 검증 대상이다.
- 브라우저의 자동 이득·소음억제·반향제거 중 하나라도 켜져 있으면 수집을 보류한다. 일부 설정이 미보고되면 기존 상대 입력 경로를 유지하고 실험적 참고임을 표시한다.

## 인터페이스

기존 `createCapture`와 `AudioPort`에 `sampleEnvironment()`와 `cancelEnvironment()`를 추가한다. 두 호출은 비동기이며 완료 결과는 기존 analysis 이벤트로 보낸다.

Promise는 명령 접수까지 기다리고 5초 수집 완료를 기다리지 않는다. 시작·취소 제어 이벤트에는 세션·설정 식별자와 환경 snapshot을 포함하되 새 오디오가 없는 만큼 프레임 식별자는 생략한다.

analysis의 환경 필드는 `state`(idle/collecting/ready/failed/unavailable), `calibrationValid`(boolean), `progress`(0..1), `noiseDbfs`, `offset`, `reason`이다. `speech`, `meterState`, `meterDbfs`, `provenance`와 기존 세션/프레임 식별 필드는 유지한다. `voiceDbfs`는 더 이상 새 목표선 또는 사용자 목소리 추정값으로 사용하지 않는다.

수집 상태와 이전 기준의 유효성은 별개다. UI의 기준선은 `calibrationValid`, 0..3 범위의 유한 offset, 현재 입력 provenance가 유효할 때만 사용한다. 수집 중에는 `meterState=calibrating`이며 표시값은 null이다.

## 대안과 선택

연속 자동 보정은 연습 중 목표선이 바뀌고 비발화 확보가 어려운 환경에서 수집이 막힐 수 있다. 수동 수집 뒤 계속 자동 보정하는 혼합 방식은 사용자가 승인한 고정 기준과 맞지 않는다. 승인된 수동 수집·고정·재측정 방식을 적용한다.

## 검증 경계

합성 프레임과 가짜 마이크의 통과는 실제 기기 검증이 아니다. 공개 WAV와 기존 RNNoise/VAD 회귀 검사를 유지하고 실제 아이폰 마이크·카페 성능·목표선 타당성을 별도로 보고한다.
