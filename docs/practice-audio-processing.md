# 발음·높낮이 녹음의 입력 처리와 발화 구분

2026-11-10 변경이다. 발음 훈련에서만 RNNoise와 libfvad를 사용하지 않는다. 높낮이 연습과 음량 측정의 소음 억제·발화 감지는 유지한다. 발음 모델은 `icig/normal-korean-ipa-translation`의 기존 고정 revision을 유지한다.

| 경로 | 처리와 사용처 |
| --- | --- |
| 웹 발음 | 48kHz 원본 PCM → 기존 FIR 16kHz → 발음 모델. RNNoise·libfvad WASM 다운로드·초기화·처리가 없다. |
| Android 발음 | record 플러그인의 48kHz PCM16 → 기존 FIR 16kHz. RNNoise·libfvad를 생성하지 않으며 모델 입력과 내 녹음 재생에 같은 결과를 사용한다. |
| 웹·Android 높낮이 | 기존 RNNoise·libfvad 경로를 유지한다. 실시간 그래프·최종 분석·재생·선택적 대본 위치 인식에 기존 처리 결과를 사용한다. |

발음 화면은 사용자의 시작·종료 조작과 녹음 진행 상태만 표시한다. 말소리 감지·발화 대기 상태를 표시하지 않는다. 높낮이의 기존 발화 판정과 비발화 피치 제외는 유지한다. 발음 비교 결과의 회색 불확실·비슷함 구분은 발화 감지와 별개이며 그대로 둔다.

VAD만으로 녹음 샘플을 삭제하거나 구간을 이어 붙이지 않는다. 말 사이의 쉼과 약한 자음, 원래 녹음 길이를 유지한다. 무음 오류에는 원신호의 분산 조건도 함께 사용한다. 소음 억제와 리샘플링이 만드는 full-scale 초과 출력은 정규 PCM 범위로 제한한다.

공통 녹음기의 `noiseReductionEnabled`와 `voiceActivityEnabled` 기본값은 `true`다. 발음 녹음기만 두 값을 `false`로 전달한다. 이 경로는 현재 프레임부터 원본 PCM을 내보내고 실제 길이의 마지막 부분 프레임까지 보존한다. 발화 판정은 만들지 않는다. RNNoise를 쓰는 높낮이 경로의 첫 지연 프레임 보상과 종료 시 drain은 유지한다. 정상 종료는 처리 중인 PCM을 기다리며 취소는 이전 세대의 늦은 응답을 폐기한다.

음량 측정 경로와 보정값은 유지한다. 추가 모델 다운로드나 음성 서버 전송은 없다. 예시 음성과 사용자가 불러온 파일에는 이 마이크 전처리를 소급 적용하지 않는다.

같은 Galaxy Jump2 녹음의 RNNoise 입력은 `아프드로`, RNNoise를 거치지 않은 동일 원본의 FIR 입력은 `아프로`로 인식됐다. 해당 비교는 증폭이나 정답 문장 보정을 사용하지 않았다. 모델·디코더·비교 색상 규칙은 변경하지 않는다.

검사는 기본 RNNoise·VAD 경로 보존, 발음 전용 원본 PCM·감지기 미사용, 첫 프레임·부분 프레임·홀수 바이트 청크·최종 샘플 수, 취소·초기화 실패를 다룬다. 로컬 진단 수집은 `VOICEMATE_LOCAL_AUDIO_DIAGNOSTICS=true` 빌드에서만 켜지며 일반 빌드는 수집하지 않는다.
