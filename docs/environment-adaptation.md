# 수동 환경 수집과 고정 참고범위

환경 수집은 사용자가 `주변 환경음 듣기`를 누를 때만 실행한다. 처음부터 선택한 상황의 기본 범위로 말하기 측정을 사용할 수도 있다. 성공적으로 수집한 환경 참고범위는 같은 마이크 연결에서 유지하며, 이후 발화나 비발화가 이어져도 자동으로 이동하지 않는다.

## 환경 수집

사용자는 말하지 않고 5초 동안 주변 소리를 수집한다. 앱 RNNoise를 적용하기 전 브라우저 입력의 에너지를 사용한다. 이 입력을 물리적인 원음이나 교정 음압이라고 부르지 않는다. 주변 사람의 대화도 환경의 일부이므로 기존 비발화 전용 필터를 적용하지 않는다. VAD가 본인과 타인을 구별하는 기능도 아니다.

버튼 요청 시점보다 앞서 시작한 대기열 프레임은 제외한다. 10ms 단위의 새 프레임 500개를 관찰하며 중복 프레임을 진행률로 세지 않는다. 다음 값은 실험적 초기 설정이다.

- 양의 유한 에너지이며 클리핑이 없는 유효 프레임이 400개 이상이어야 한다.
- 클리핑 프레임 비율이 10% 이상이면 수집 실패다.
- 유효 에너지의 사분위 범위가 12dB를 초과하면 불안정한 수집으로 처리한다.
- 유효 에너지의 중앙값을 `10*log10`으로 변환한다. 디지털 무음으로 환경 기준을 만들어내지 않는다.

RNNoise와 VAD가 준비되어 현재 분석 프레임을 제공할 때만 수집한다. 수집 중에는 발화 막대를 비우며 기존 마이크 연결을 유지한다. 수집 완료 때문에 마이크를 중지하거나 다시 열지 않는다.

## 기준선 규칙과 한계

상황별 기본 하한과 상한에 같은 보정값을 더한다. 보정값은 `clamp((noiseDbfs + 60) / 10, 0, 3)`을 소수 첫째 자리로 반올림한다. 예를 들어 -60dBFS 이하에서는 0, -50에서는 1, -40에서는 2, -30 이상에서는 최대 3 참고 단위다. 이 숫자는 구현용 제한 규칙이며 기기별 적정 발성량이나 안전 음압을 검증한 결과가 아니다.

환경 수집값과 발화 막대는 처리 경로가 다르다. 소음억제 전 환경음 수치에 임의의 여유값을 더해 소음억제 후 발화의 절대 목표라고 주장하지 않는다. 실제 환경과 기기별 비교가 이루어지면 규칙을 조정해야 한다. 현재 표시 오프셋 +114도 사용자가 웹사이트와 앱 사이에서 관측한 차이이며 기준 소음계로 교정한 SPL/dBA가 아니다.

브라우저 자동 이득·소음억제·반향제거 중 하나라도 켜졌거나 잘못된 형식이면 수집을 보류한다. 세 설정이 모두 false로 보고되면 기존 verified 경로를 쓰며, 일부가 미보고되고 나머지가 false이면 relative_input 경로로 실험적인 참고값만 표시한다. 미보고를 false로 간주하지 않는다. false 보고 역시 장치의 숨은 처리 부재를 증명하지 않는다.

## 유지·취소·초기화

수집 단계와 기존 성공 기준의 유효성은 별개다. 재측정 중에도 이전 기준선은 유지하며, 사용자 취소 또는 통계 품질 실패는 같은 입력 조건의 이전 성공 기준을 보존한다. 최초 수집이 실패하면 기본 상황 범위를 유지한다.

입력 공백, 오래된 분석 프레임, 장치·설정 변경, 캡처 중지, 화면 이탈은 기준을 폐기한다. 같은 연결에서 수집이 끝나 말하기로 전환하는 것은 초기화 사유가 아니다. 긴 발화나 비발화 때문에 완료 기준이 5초 뒤 만료되는 이전 자동 학습 동작은 적용하지 않는다.

명령 Promise는 시작·취소 요청을 반영한 뒤 완료된다. 수집 결과는 기존 analysis 이벤트로 전달한다. 제어 이벤트는 새 오디오 프레임이 아니므로 seq/sampleStart 필드를 강제로 생성하지 않는다. 늦게 끝난 이전 세션의 이벤트로 새 상태를 복원하지 않는다.

## 실제 발화 표시

기존 RNNoise와 별도 libfvad의 발화 게이트는 유지한다. 10ms 프레임 3개에서 연속 발화가 확인되면 RNNoise 처리 후 RMS를 표시한다. 이는 실험적 30ms 확인 조건이며 실제 짧은 발화의 검출 성능을 보증하지 않는다. 비발화·불확실·클리핑·발화 판정 실패·오래된 프레임에서는 막대를 비운다. 타인의 목소리도 포함될 수 있다.

환경 수집 결과에서 원시 에너지를 빼서 별도의 사용자 목소리 크기라고 표시하지 않는다. RNNoise 전후 차이도 물리적인 잡음량으로 해석하지 않는다.

## 검증 경계

새 환경 수집·기준 유지·배경 대화·취소·기기 변경·중복 프레임과 기존 RNNoise/VAD 경로를 합성·WASM·위젯 검사로 검증한다. 이 검사는 실제 마이크, iPhone Safari, 실제 카페에서의 수집 성공률이나 목표선의 타당성 검증을 대체하지 않는다. 실제 기기 검증 결과 없이 적정 발성량 또는 정확한 소음계라는 표현을 사용하지 않는다.
