# 환경 변화 추적 설계와 검증 경계

+114는 사용자가 실험에서 웹사이트 측정값과 앱의 보정 전 값 사이 차이를 직접 관측해 얻은 보정값이다. 기준 소음계를 사용한 절대 SPL 교정이나 모든 기기·입력 경로의 유효성을 뜻하지 않는다.

기존 상황 선택이 시작 조건이다. 처음부터 시끄러운 환경을 자동 분류하지 않는다. 초기 비발화 기준과 같은 입력 조건에서 이후의 변화만 추적한다. 기존 상황별 범위도 새 발화 지표에 검증된 목표가 아닌 참고값이다.

원본은 브라우저가 제공한 신호다. AGC/noiseSuppression/echoCancellation이 모두 false로 보고되면 검증된 설정 경로를 쓴다. 일부 설정이 제공되지 않고 나머지가 false면 별도의 실험적 상대 입력 추정을 쓴다. 하나라도 활성화되거나 잘못된 형식이면 조정을 보류한다. 미보고를 false로 취급하지 않는다. 상대 입력 모드는 물리 음압이나 원음이 아니며 AGC 변화와 환경 변화를 구분할 수 없다. 따라서 보정된 발화 수준을 산출하지 않는다. false 보고 역시 장치의 숨은 처리가 없다는 보장은 아니다.

단일 worklet에서 원본 에너지를 측정하고 RNNoise 뒤의 별도 VAD로 발화를 판별한다. libfvad 양성에 더해 앞뒤 RNNoise 점수가 모두 0.5 이상이어야 발화로 표시한다. libfvad 음성이면서 두 점수가 모두 0.2 미만일 때만 비발화로 인정하고, 나머지는 불확실로 취급한다. 특히 libfvad 양성이 RNNoise 조건을 충족하지 못하면 배경 학습에 사용하지 않는다. 발화·판정 충돌·클리핑은 환경 근거에서 제외하지만 두 모델의 오탐과 누락을 없앨 수는 없다. RNNoise 전후 차이는 물리적인 잡음량이 아니다.

승인된 초안의 별도 16kHz 변환 대신 libfvad에 48kHz·10ms 프레임을 전달한다. 확인한 upstream 소스의 48kHz 경로는 자체 리샘플러로 8kHz로 변환해 VAD를 실행한다. npm 2.0.7 바이너리는 고정 upstream 커밋의 추적된 임베디드 바이너리와 동일하다. 해당 소스에서의 재현 빌드는 확인되지 않았다. RNNoise 분석·합성의 한 프레임 지연에 맞춰 처리 출력은 직전 원본 에너지와 짝지으며, RNNoise 점수는 앞뒤 두 프레임을 모두 보수적으로 확인한다. 합성 신호의 지연 검사는 실제 음성 경계 정확도 검증을 대체하지 않는다.

실험 시작값은 준비 500ms, 발화 앞 200ms/뒤 500ms 제외, 최근 3초 안의 적격 비발화 1초 초기화, 잡음 신선도 5초, 중앙값/IQR 3dB/적격시간 EMA 2초다. 목표 보정과 현재 보정의 차이가 0.5단위 이상이면 상승 후보를 시작하고, 0.25단위 이내에서는 유지한다. 후보는 새 비발화 1초와 경과 2초, 증거 공백 2초 이하를 요구한다. 중복·묵은 표본을 증거로 세지 않는다. 디지털 무음만으로는 기준을 만들지 않으며, 양의 안정된 비발화 에너지가 들어오면 수집을 재개한다.

worklet의 AudioContext 표본 시각과 수신 시점의 AudioContext 현재 시각을 비교해 1초 이상 늦거나 250ms 이상 앞선 프레임은 보류한다. 시계를 수신 시각으로 재설정하지 않으며 같은 세션의 최초 환경 기준과 기존 보정은 보존한다. 다시 신선한 표본을 받아도 비발화 증거를 다시 수집한다.

worklet에 입력 채널이 없어지는 공백이 발생하면 발화 표시를 즉시 비우고 분석을 보류한다. 입력이 돌아오면 RNNoise·VAD 상태와 부분 RMS 창을 초기화하고 새 오디오 표본 시각으로 분석을 재개한다. 추정기의 이전 구간 순번·마지막 근거 시각·발화 상태도 초기화해 새 구간의 발화 및 비발화 판정이 즉시 반영되도록 한다. 같은 세션의 최초 환경 기준과 보정값은 유지하되 잡음 증거를 다시 수집한다. 기존 1.5초 입력 프레임 제한이 먼저 발생하면 캡처가 중지되므로 사용자가 다시 시작해야 한다.

보정 후보는 초기 잡음 대비 변화의 0.5배이며 0..3 참고 단위다. 한 번에 최대 1단위만 변경하고 다시 새 증거를 요구한다. 큰 변화도 상한 3에서 제한하며 기본 범위로 갑자기 되돌리지 않는다. 이 상한은 안전 음압을 뜻하지 않는다.

발화 추정은 Pvoice=max(Pinput-Pnoise,0)이다. fresh/stable/same-settings/speech 조건과 Pvoice/Pnoise>=2에서만 값을 제공한다. Pnoise=0, 음수차, 낮은 SNR, stale, uncertain은 보류한다. 같은 세션의 stale 재확보는 초기 기준점을 유지하지만 장치/설정/세션 변경은 전부 초기화한다.

OFF/초기 RNNoise 실패에서 원본 수준 이벤트가 내부에 남더라도 확인된 발화 막대를 표시하지 않는다. 게이지는 실행 중이고 발화 판정과 meterState가 모두 speech이며 유효한 meterDbfs가 있을 때만 표시한다. RNNoise 실행 오류는 기존대로 종료한다. VAD만 실패하면 분석을 보류하고 확인된 발화 막대를 비운다. 탭 이탈과 입력 누락은 기존 중지 동작을 따른다.
VAD 다운로드 및 본문 읽기에 별도 1.5초 제한을 두며, 실패하거나 정체되면 해당 요청을 취소하고 RNNoise 초기화는 계속한다.

합성 테스트와 WASM 테스트는 실기기 검증이 아니다. 저장된 예시 음성 3개를 원래 크기와 20dB 낮춘 크기로 처리했을 때 기존 VAD 양성 프레임의 70~85%가 새 조건에서도 유지됐다. 이는 다양한 사람 음성이나 실제 박수·개 짖음 분리 성능을 보증하지 않는다. 실제 마이크와 iPhone Safari, 작은 타인 음성, 겹친 발화, 입력 이득/거리 변화는 별도 검증해야 한다. 실제 녹음이나 권한 요청은 사용자 승인 전 수행하지 않는다.

상대 입력 모드에서는 지연·공백 또는 세션·기기·설정 변경 시 기존 기준과 보정값을 폐기하고 새 비발화 증거를 수집한다. 이 모드의 `voiceDbfs`는 항상 null이다. 범위선 애니메이션은 표시만 보간하며 판정 기준과 지속성 요구는 바꾸지 않는다.
