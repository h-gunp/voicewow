# 환경 변화 추적 설계와 검증 경계

+114는 사용자가 실험에서 웹사이트 측정값과 앱의 보정 전 값 사이 차이를 직접 관측해 얻은 보정값이다. 기준 소음계를 사용한 절대 SPL 교정이나 모든 기기·입력 경로의 유효성을 뜻하지 않는다.

기존 상황 선택이 시작 조건이다. 처음부터 시끄러운 환경을 자동 분류하지 않는다. 초기 비발화 기준과 같은 입력 조건에서 이후의 변화만 추적한다. 기존 상황별 범위도 새 발화 지표에 검증된 목표가 아닌 참고값이다.

원본은 브라우저가 제공한 신호다. AGC/noiseSuppression/echoCancellation의 요청값과 적용값을 구분한다. 실제 설정이 셋 모두 false인 경우만 자동 분석을 지원한다. false도 장치의 숨은 처리가 없다는 보장은 아니다.

단일 worklet에서 원본 에너지를 측정하고 RNNoise 뒤의 별도 VAD로 발화를 판별한다. RNNoise 내부 점수도 보조 거부 조건으로 사용한다. 모든 화자의 발화·판정 충돌·클리핑을 제외하지만 VAD 누락을 없앨 수는 없다. RNNoise 전후 차이는 물리적인 잡음량이 아니다.

승인된 초안의 별도 16kHz 변환 대신 libfvad에 48kHz·10ms 프레임을 전달한다. 확인한 upstream 소스의 48kHz 경로는 자체 리샘플러로 8kHz로 변환해 VAD를 실행한다. npm 2.0.7 바이너리는 고정 upstream 커밋의 추적된 임베디드 바이너리와 동일하다. 해당 소스에서의 재현 빌드는 확인되지 않았다. RNNoise 분석·합성의 한 프레임 지연에 맞춰 처리 출력은 직전 원본 에너지와 짝지으며, RNNoise 점수는 앞뒤 두 프레임을 모두 보수적으로 확인한다. 합성 신호의 지연 검사는 실제 음성 경계 정확도 검증을 대체하지 않는다.

실험 시작값은 준비 500ms, 발화 앞 200ms/뒤 500ms 제외, 최근10초 적격 비발화3초 초기화, 잡음 신선도5초, 중앙값/IQR3dB/적격시간 EMA2초다. 목표 변경은 진입3dB/해제1.5dB, 새 비발화3초와 경과5초와 증거공백2초 이하를 요구한다. 중복·묵은 표본을 증거로 세지 않는다.

worklet의 AudioContext 표본 시각과 수신 시점의 AudioContext 현재 시각을 비교해 1초 이상 늦거나 250ms 이상 앞선 프레임은 보류한다. 시계를 수신 시각으로 재설정하지 않으며 같은 세션의 최초 환경 기준과 기존 보정은 보존한다. 다시 신선한 표본을 받아도 비발화 증거를 다시 수집한다.

보정 후보는 초기 잡음 대비 변화의 0.5배이며 0..3 참고 단위다. 한 번에 1단위만 변경하고 다시 새 증거를 요구한다. 상한 초과는 지원 불가다. 이 상한은 안전 음압을 뜻하지 않는다.

발화 추정은 Pvoice=max(Pinput-Pnoise,0)이다. fresh/stable/same-settings/speech 조건과 Pvoice/Pnoise>=2에서만 값을 제공한다. Pnoise=0, 음수차, 낮은 SNR, stale, uncertain은 보류한다. 같은 세션의 stale 재확보는 초기 기준점을 유지하지만 장치/설정/세션 변경은 전부 초기화한다.

OFF/초기 RNNoise 실패는 기존 원본 표시만 유지한다. RNNoise 실행 오류는 기존대로 종료한다. VAD만 실패하면 기존 음량 표시는 유지하고 분석을 보류한다. 탭 이탈과 입력 누락은 기존 중지 동작을 따른다.
VAD 다운로드 및 본문 읽기에 별도 1.5초 제한을 두며, 실패하거나 정체되면 해당 요청을 취소하고 RNNoise 초기화는 계속한다.

합성 테스트와 WASM 테스트는 실기기 검증이 아니다. 실제 마이크와 iPhone Safari, 작은 타인 음성, 겹친 발화, 입력 이득/거리 변화는 별도 검증해야 한다. 실제 녹음이나 권한 요청은 사용자 승인 전 수행하지 않는다.
