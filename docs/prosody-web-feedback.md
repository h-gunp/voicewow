# 높낮이 연습 웹 지원과 대본 가이드

이 변경은 `main`의 `a1654a1277db84311d07a2dba6efa6354d072dba`를 기준으로 한 기능 브랜치의 제안이다. 웹에서도 높낮이 연습을 열고, 단계별로 화면을 넘기며, 대본 전체의 가이드를 한 번에 준비할 수 있다. PR 검토와 공개 사이트 배포는 별도로 진행한다.

## 달라진 동작

- Flutter Web의 높낮이 탭에서 안내문 대신 같은 사이트 안의 실제 웹 연습 화면을 연다. Android의 기존 Flutter 화면·녹음·분석 구현은 유지한다.
- 연습 방법 선택(준비된 문구 / 내 대본)을 1→2→3 순서 안내보다 위에 둔다. 가이드 준비 → 녹음 → 결과를 한 화면씩 가로로 넘긴다. 좌우 스와이프, 단계 버튼, 이전·다음 버튼을 함께 제공한다. 긴 글과 자세한 결과만 화면 안에서 세로로 살펴본다.
- 녹음·합성·분석 중에는 단계 이동을 막고 새 결과를 받아들인 뒤 결과 화면으로 이동한다. 아직 가이드가 없는 대본은 녹음 단계로 갈 수 없다. 휴대폰에서 녹음 버튼은 아래에 고정하고 준비·녹음·결과를 한 화면에 작게 겹쳐 놓지 않는다.
- 대본을 문장별로 나누고 지금 읽을 문장, 전체 목록, 이전·다음, 결과에서 다음 문장 이동을 제공한다. 긴 문장은 약 50자, 최대 60자의 짧은 조각으로 나눈다. 원문 문장과 조각 번호를 유지한다. 최대 2,000자·60조각이다. 줄바꿈으로 원하는 연습 경계를 정할 수 있다.
- ‘전체 가이드 만들기’를 한 번 누르면 모든 문장/조각의 실제 음성을 차례로 합성·분석하고 문장별 가이드를 보관한다. 생성 버튼을 문장마다 누르지 않는다. 한 worker와 준비된 모델을 재사용하며 병렬 합성은 하지 않는다.
- 준비된 AI 가이드와 사용자가 연결한 참고 파일은 재사용한다. 취소·개별 오류 뒤에는 남은 문장만 이어서 만들고, 이미 준비한 다른 문장과 기존 녹음 결과를 지우지 않는다. 전체 완료 수와 문장별 준비 상태를 보여준다. 준비 도중 ‘멈추고 준비된 문장 연습하기’로 시작할 수 있다.
- 일부 문장에 오류가 나도 다음 문장의 준비를 계속한다. 성공하지 않은 문장은 준비됨으로 표시하지 않는다. 필요할 때만 ‘가이드 수정 옵션’에서 선택한 문장을 다시 만든다.
- 대본 전체를 하나의 음성 파일로 만든 뒤 단어 위치를 추정해 자르는 방식은 아니다. 짧게 나눈 각 문장의 실제 합성 음성과 그래프를 한 번의 버튼 동작으로 준비한다.
- 대본 수정 후 다시 준비하지 않은 상태에서는 녹음·가이드 생성을 막아 이전 문장 음성과 새 대본이 섞이지 않게 한다.
- 준비된 가이드의 측정 가능한 소리만 보고 시간 구간을 3→2→1개로 선택한다. 사용자 녹음이나 비교 오차에 맞춰 경계를 바꾸지 않는다. 그래프·버튼·클릭 범위가 같은 경계를 사용한다.
- 시작·끝 부근에 자음이나 쉼이 있어도 서로 독립된 실제 측정 블록을 사용할 수 있다. 없는 높낮이는 여전히 비워 두며 비교 근거가 부족하면 안내를 보류한다.
- 짧은 원본 파일(1.8초 이하)은 전체를 재생한다. 긴 구간은 선택 범위 앞뒤 최대 0.25초를 함께 재생한다. 이는 듣기 편의를 위한 값이며 평가 기준이 아니다. 원본 오프셋은 한 번만 더하고 파일 끝에서 재생 범위를 제한한다.
- 구간의 시작·끝 시간과 연습한 전체 문구를 표시한다. 다시 연습할 때는 임의 시간으로 자른 음절 대신 같은 문장 전체를 읽는다. 새 녹음 분석이 실패하면 이전 결과를 유지한다.
- 웹 화면 이탈 시 녹음 트랙, 음성 생성 작업, 재생, 타이머를 중지한다. 자동 녹음·자동 합성·자동 재생은 하지 않는다.

## 아직 해결하지 않은 항목

**‘안녕하세요’의 ‘안/녕/하/세/요’가 정확히 어느 시각에 나오는지는 표시하지 않는다.** 현재 높낮이 추정과 DTW는 음성 인식이나 대본 정렬이 아니다. 글자 수 비율로 시간을 만들어 붙이지 않았다.

이를 구현하려면 대본과 실제 음성 사이의 단어·음절 정렬을 별도로 도입하고 한국어 및 대상 사용자 음성으로 오차를 확인해야 한다. 대안으로 짧은 구절별 가이드를 독립 생성해 각 구절 전체를 연습할 수 있지만, 원래 문장의 연음과 억양이 달라지므로 전체 음성의 정확한 단어 정렬이라고 표현하면 안 된다.

문장·조각 나누기는 글을 짧게 연습하기 위한 기능이다. 사용자가 해당 문장을 실제로 읽었는지는 자동으로 확인하지 않는다. 다른 사람의 목소리 구별 및 완전한 소음 제거도 포함하지 않는다.

## 파일과 실행

- 웹 소스·모델 실행 코드·준비된 예시: `apps/client/web/prosody/`
- 웹 동작·분석 검사: `tools/prosody-web-tests/`
- Flutter의 웹 전용 연결: `apps/client/lib/features/prosody/presentation/prosody_web_frame*.dart`
- 모델과 오픈소스 고지: `apps/client/web/prosody/THIRD-PARTY-NOTICES.md`

웹 소스는 Flutter의 `web/` 안에 있으므로 별도 복사 과정 없이 다음 빌드에 포함된다.

```sh
cd apps/client
flutter pub get
flutter build web --release
python3 -m http.server 8772 --bind 127.0.0.1 --directory build/web
```

통합본은 `http://127.0.0.1:8772/`, 높낮이 단독 화면은 `http://127.0.0.1:8772/prosody/index.html`이다. 마이크는 HTTPS 또는 localhost에서 사용한다. 내 대본의 Supertonic 가이드 생성은 첫 실행에 약 400MB의 공개 모델을 내려받는다. 녹음과 대본은 브라우저 안에서 처리하며 새로고침·탭 이탈 시 유지되지 않는다.

검사:

```sh
node --test tools/prosody-web-tests/*.test.mjs
cd apps/client
flutter test test/prosody/prosody_web_frame_contract_test.dart
```

## 확인 결과

- 웹 검사 108개 통과(합성 입력, 실제 예시 WAV 재분석, 침묵·결측, 대본 수정, 문장 이동, 정리 동작 포함).
- Flutter 전체 검사 226개 통과(웹 프레임 계약·종료 검사 6개 포함). Dart 분석 통과.
- Flutter Web release 빌드 통과. 기존 `flutter_tts`의 Wasm 사전 검사 경고는 남아 있으며 이번 빌드는 JavaScript 대상이다.
- 실제 브라우저에서 통합 탭 열기, 데모 비교, 두 구간 선택, 전체 가이드 재생, 음량 화면 복귀와 휴대폰 크기 레이아웃, 실제 가로 넘기기·단계 버튼, 대본을 5개 문장/조각으로 나누고 선택하는 동작 확인.
- 실제 브라우저에서 ‘안녕하세요. 반갑습니다.’ 두 문장을 한 번의 버튼 동작으로 Supertonic 합성·분석하여 2/2개 준비 완료를 확인했다. 문장을 바꾼 뒤 추가 생성 없이 녹음 단계에 진입할 수 있었다. 이 확인은 저장된 모델 캐시를 사용했다.
- 실제 사용자 마이크 녹음, 실제 Android/iPhone 기기, 긴 대본의 새 AI 음성 생성 품질은 이번 검증 범위에 포함하지 않았다. 검사는 임상적 효과나 억양 평가 정확도를 입증하지 않는다.

이 변경은 기능 브랜치와 PR로 제공한다. main 병합과 공개 통합 사이트 배포는 통합 담당자가 진행한다. 웹 전용 가로 넘김과 대본 전체 가이드 생성은 이번 웹 경로에 적용되며, Android는 기존 Flutter 직접 구현을 유지한다.
